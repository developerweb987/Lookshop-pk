# 🛍️ LookShop PK – Premium AI-Powered E-Commerce Platform

LookShop PK is a modern, scalable, and high-performance **Next.js-based e-commerce web application** designed to deliver a seamless online shopping experience. Built with the latest technologies, it combines speed, clean UI, and **AI-powered chatbot integration** to enhance user interaction.

---

## 🚀 Live Overview

- ⚡ Fast & Optimized with Next.js App Router
- 🛒 Complete E-Commerce UI
- 🤖 AI Chatbot Integration (Claude-based)
- 📱 Fully Responsive Design
- 🎯 Clean & Scalable Architecture

---

## 🧠 Tech Stack

### Frontend
